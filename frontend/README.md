# MS Aroma Frontend

Astro 静态站点。完整的数据准备、开发和构建说明见仓库根目录的 `README.md`。

常用命令：

```bash
npm run generate       # 生成图片和商品 JSON
npm run dev            # 启动开发服务器
npm run check          # Astro/TypeScript 检查
npm run build          # 构建现有静态数据
npm run rebuild        # 重新生成数据并构建
npm run preview        # 预览构建结果
```
